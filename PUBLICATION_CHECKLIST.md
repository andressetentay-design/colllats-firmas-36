# Publication readiness checklist

This checklist is a planning aid, not a statement that these steps have been completed.

## Repository

- [x] Add a bilingual landing page that links to the manuscript and states current limitations.
- [x] Add guidance for constructive, verifiable feedback.
- [x] Add cautious draft announcements and a pre-publication checklist.
- [ ] Review the PDF and replace the README’s general description with a precise, independently checked abstract.
- [ ] Add author-preferred name, contact, and affiliations only with the author’s approval.
- [ ] If code or computational claims are part of the work, publish source, data, environment details, and exact reproduction commands.
- [ ] Select an explicit license. Do not assume the manuscript is openly licensed until the rights holder chooses one.
- [ ] Add a citation file and versioned archival record after author, date, and version are confirmed.
- [ ] Consider a GitHub Release only after a stable version and release notes are ready.

## External sharing

- [ ] Review each venue’s scope, policies, and self-promotion rules.
- [ ] Use the drafts in `announcements/README.md` only after checking every claim against the PDF.
- [ ] Do not describe the manuscript as peer-reviewed or as a proof of the conjecture unless that is accurate and substantiated.
- [ ] Submit to a preprint service only after checking its current requirements and preparing the source and metadata it requests.
