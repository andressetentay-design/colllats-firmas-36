# Contributing / Comentarios

## Español

Gracias por leer el manuscrito. Para que las observaciones sean fáciles de comprobar:

- Identifica la página, definición, ecuación o teorema relevante.
- Describe el razonamiento o cálculo que sustenta tu comentario.
- Si detectas un contraejemplo, incluye el valor inicial y cada paso necesario para verificarlo.
- Mantén un tono respetuoso y enfócate en el argumento matemático.
- No publiques datos personales ni información privada en issues.

Este repositorio contiene actualmente un PDF y no incluye código o datos de verificación. No se debe presentar una comprobación independiente como realizada a menos que efectivamente se haya hecho.

## English

Thank you for reviewing the manuscript. To make feedback verifiable:

- Point to the relevant page, definition, equation, or theorem.
- Explain the reasoning or computation behind your comment.
- For a counterexample, include the starting value and enough steps to check it.
- Keep feedback respectful and focused on the mathematical argument.
- Do not post personal or private information in issues.

The repository currently contains a PDF and no verification code or data. Do not describe independent verification as completed unless it has actually been performed.
